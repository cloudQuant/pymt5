关于作者
========

`cloudQuant <https://github.com/cloudQuant>`_ 是 **pymt5** 的作者和维护者。
作者的 `GitHub 公开主页 README
<https://github.com/cloudQuant/cloudQuant#readme>`_ 将 cloudQuant 介绍为一名
“构建系统化交易基础设施的量化工程师”（Quant engineer building the
infrastructure behind systematic trading）。

GitHub 主页及其公开仓库是了解作者当前工作的最佳入口。下方动态区域由浏览器
读取 GitHub 公开元数据，而不是在构建文档时保存一份容易过期的快照。请求不使用
GitHub Token、Cookie 或登录信息。即使禁用 JavaScript、网络不可用或 GitHub
限制匿名请求，本页的作者介绍和链接仍然可用。
