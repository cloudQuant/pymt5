About the author
================

`cloudQuant <https://github.com/cloudQuant>`_ is the author and maintainer of
**pymt5**. The author's `public GitHub profile README
<https://github.com/cloudQuant/cloudQuant#readme>`_ introduces cloudQuant as a
"Quant engineer building the infrastructure behind systematic trading."

The profile and its public repositories are the best place to follow the
author's current work. The live sections below read public GitHub metadata in
your browser instead of taking a one-time snapshot when this documentation is
built. No GitHub token, cookie, or login is used. If JavaScript is disabled, the
network is unavailable, or GitHub limits anonymous requests, the introduction
and links on this page remain available.
